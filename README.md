# محاكي إدارة المرحلة الانتقالية السورية | Syrian President Simulator

محاكاة استراتيجية واقتصادية متقدمة ونظام إدارة حكم سياسي تفاعلي مبني بتقنيات الويب الحديثة (**Svelte 5** و **Tailwind CSS**)، يضع اللاعب في موقع قيادة الدولة السورية خلال المرحلة الانتقالية بعد سقوط النظام، لإدارة التوازنات المعقدة بين الاقتصاد الكلي، إعادة الإعمار الإقليمي، استعادة السيادة الوطنية، والاستقرار المعيشي والسياسي.

---

## 🏛️ نظرة عامة على المشروع (Project Overview)

تم تصميم المحاكي وفق نماذج رياضية واقتصادية دقيقة مستندة إلى بيانات واقعية من تقارير **البنك الدولي (World Bank)** لتقييم الأضرار المادية، وتقارير **الأمم المتحدة لتنسيق الشؤون الإنسانية (UN OCHA)**، وبيانات **برنامج الأغذية العالمي (WFP)** والمصرف المركزي السوري.

يمتد الدور الواحد لـ **6 أشهر** (نصف سنة: موسم الحصاد H1 / موسم الشتاء H2) على مدار **40 دوراً** (20 عاماً)، تنتهي بتقييم تاريخي شامل عبر "محرك استشراف المئوية" (Century Projection Engine).

## ⚙️ الأنظمة والمحركات الرئيسية (Core Systems)

### 1. محرك الاقتصاد الكلي والسياسة النقدية المزدوجة (Macroeconomic & Dual Currency Engine)
- **احتياطي النقد الأجنبي ($ Reserves) ومدى الكفاية (Runway):**
  - تتبع دقيق لتدفقات الدولار الصعبة: مبيعات الفوسفات، ترانزيت الشاحنات بكافة المعابر الحدودية، رسوم عبور الأجواء، عوائد النفط وحصة العشائر، الحوالات الخارجية، والقروض السيادية.
  - نفقات النقد الأجنبي: استيراد القمح، المحروقات والفيول لمحطات التوليد، خدمة الديون، والاستثمارات الرأسمالية لشبكة الكهرباء (CapEx).
  - إفلاس سيادي فوري عند نفاد الاحتياطي النقدي الأجنبي (`reservesUSD <= 0`).
- **خزينة الدولة بالليرة السورية (SYP Treasury) والعجز السيادي السالب:**
  - إيرادات الضرائب المحلية، الجمارك، والرسوم.
  - تغطية كتلة الرواتب الحكومية (أكثر من 850 ألف موظف)، شبكة الدعم التمويني، ودعم أسعار الخبز والمحروقات.
  - **السحب على المكشوف والعجز السالب:** عند تجاوز النفقات للإيرادات والسيولة، يسجل رصيد الخزينة قيماً سالبة صريحة (مثل `-1.36T ل.س`) مع شارة عجز حمراء، دون فرض طباعة نقد قسرية فورية، محاكياً الإدارة المالية الواقعية للديون الحكومية.
- **سعر الصرف الموازي (Parallel FX Rate) والكتلة النقدية (M2):**
  - تسعير ديناميكي يتأثر بحجم الإصدار النقدي (Seigniorage)، استنزاف الدولار، ومستوى الثقة العامة، ومزادات التدخل للمصرف المركزي.
  - حساب الأجر الحقيقي للموظف العام بالدولار دورياً.

### 2. الأنظمة الإقليمية والمكانية (14 المحافظات السورية)
- خريطة تفاعلية لـ 14 محافظة سورية مع تمييز دقيق للمساحات والمناطق.
- **مؤشرات كل محافظة:**
  - **مؤشر الاحتقان والتمرد المحلي (PRRI):** (هادئ CALM، متوتر TENSE، اضطرابات RIOT، تمرد REVOLT).
  - **نسبة الأضرار المادية ومستوى الإعمار:** مستندة بالمليون دولار إلى تقرير البنك الدولي للمحافظات الـ 14 (حلب، ريف دمشق، حمص، دمشق... إلخ).
  - **ساعات التغذية والظلام اليومية:** تتأثر بقدرة الشبكة الوطنية والتوليد المحلي.
  - **نسبة تلوث الأراضي بالألغام:** تتطلب توجيه جهود فرق الهندسة ونزع الألغام.
  - **المشاريع الاستراتيجية الإقليمية:** تنفيذ مشاريع تنموية كبرى لكل محافظة (صوامع حبوب، تأهيل محطات تحويل، تأهيل مرافئ، ري زراعي).

### 3. مجلس الوزراء والقرارات السيادية (Ministries & Decrees)
- إدارة الوزارات الاستراتيجية (المالية، الاقتصاد، الدفاع، الداخلية، الخارجية، الكهرباء، الزراعة).
- إنفاق **الرصيد السياسي (Political Capital)** لإصدار المراسيم السيادية وإدارة الأزمات:
  - هيئة النزاهة وتدقيق الأصول ومكافحة الفساد.
  - المنصة الرقمية لرد الملكيات العقارية للاجئين والنازحين.
  - الحملة الوطنية لضبط الحدود ومكافحة التهريب.
  - ميثاق التفاهم العشائري وتأمين الترانزيت الشرقي.
  - حوافز استقطاب الكفاءات والمغتربين (Brain-Gain).
  - تسوية أصول الأوليغارشية والمحتكرين.

### 4. شريط المؤشرات التفاعلي والتوقعات الفورية (Predictive Preview Top Ribbon)
- شريط علوي حي ومستمر يُظهر الإحصاءات القومية الرئيسية:
  - خزينة الدولة (ل.س) مع إظهار المبالغ السالبة وحالات العجز.
  - الاحتياطي الدولاري ($) ومدى الكفاية بالأشهر.
  - سعر الصرف الموازي لليرة.
  - متوسط أجر الموظف الحقيقي ($).
  - الرصيد السياسي ومستوى الثقة الشعبية.
  - المؤشر الوطني للاحتقان والتمرد (مترجم بالكامل للغة العربية).
  - ساعات التغذية الكهربائية اليومية.
- **محاكاة البروفة الحية (Live Rehearsal Mode):**
  - بمجرد تعديل أي سياسة في القوائم الجانبية، يُظهر الشريط فوراً القيمة المتوقعة للدور القادم، فارق التغير (Delta)، ونسبة التغير المئوية (%) مع تلوين أخضر/أحمر حسب أثر القرار.
  - كبسولات تسعير مستقلة ثنائية العملة (USD / SYP) تُظهر الكلف والمكاسب بوضوح.

### 5. نظام الأزمات والتحكيم (Dynamic Crises & Fail States)
- سحب أحداث عشوائية قائمة على حالة المحافظات والقرائن السياسية (إضرابات، فيضانات، توترات حدودية، أزمات وقود).
- شروط خسارة متعددة:
  - إفلاس الاحتياطي الأجنبي.
  - انهيار الثقة العامة إلى الصفر.
  - اشتعال التمرد الشامل في أغلبية المحافظات.
  - نفاد الرصيد السياسي وتفكك الجهاز التنفيذي.

## 🚀 التشغيل والتطوير المحلي (Local Development)

### المتطلبات الأساسية:
- **Node.js** (الإصدار 18 أو أحدث)
- **npm** أو **pnpm**

### خطوات التثبيت والتشغيل:
```bash
# 1. استنساخ المستودع
git clone git@github.com:hadealahmad/syrian-president-simulator.git
cd syrian-president-simulator

# 2. تثبيت الحزم البرمجية
npm install

# 3. تشغيل خادم التطوير المحلي
npm run dev

# 4. التحقق من سلامة الأنواع والشيفرة البرمجية
npm run check

# 5. بناء نسخة الإنتاج
npm run build
```
